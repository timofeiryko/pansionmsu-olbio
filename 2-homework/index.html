Приготовить ряд фосфатных буферов

Для эксперимента нужен ряд фосфатных буферов: по 100 мкл с каждым значением pH из таблицы. Есть два исходных раствора: NaH₂PO₄ и Na₂HPO₄, оба по 100 мМ

Рассчитайте объёмы компонентов и округлите до целых микролитров. Используйте pKₐ = 6,8

\mathrm{pH}=\mathrm pK_a+\log_{10}\frac{[\ce{HPO4^{2-}}]}{[\ce{H2PO4^-}]}
