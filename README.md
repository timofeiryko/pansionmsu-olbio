# Олимпиадная биология · Reveal.js

## GitHub Pages

Презентация публикуется из корня ветки `main` репозитория `timofeiryko/olympiad-biology`. После изменения HTML, CSS или медиа сделайте commit и push — GitHub Pages обновит сайт автоматически. Для сайта используется `index.html` с отдельными локальными ресурсами; автономный HTML собирается командой `python package.py` для скачивания и показа без интернета.

## Открыть

- `index.html` — основная редактируемая презентация. Открывается двойным щелчком.
- `olympiad-biology.html` — автономная копия: шрифты, фотографии, видео, CSS и Reveal.js встроены в файл. Для показа, включая видео, не нужен интернет. Внешние ссылки требуют подключения.
- `styles.css` — тема и композиции, `app.js` — настройки Reveal.js и панель управления.
- `assets/` — изображения, локальные шрифты Commissioner и видео кристаллизации.
- `vendor/` — Reveal.js 6.0.2 и плагин заметок. Лицензия включена.

## Управление

Стрелки / пробел — вперёд и назад. Esc или O — обзор. F — полный экран. На телефоне можно листать свайпами. Список внизу позволяет перейти к любому слайду.

S — окно докладчика с таймером и следующим слайдом. Для него запустите локальный сервер: `python -m http.server 8766 --bind 127.0.0.1` в папке проекта, затем откройте <http://127.0.0.1:8766/>. Для Windows также есть `serve.ps1`. Простой показ работает без сервера.

## Редактировать и добавлять слайды

Редактируйте **index.html**. Каждый слайд — отдельный `<section class="slide">` внутри `<div class="slides">`. Текст находится в обычных `h2`, `h3`, `p`, `li`. Никаких сборщиков или npm для редактирования не требуется.

Чтобы добавить слайд, скопируйте подходящую секцию, задайте уникальный `id`, обновите `data-title`, заголовок и содержимое. Счётчик и список слайдов обновляются автоматически при открытии. Размер холста — 1280 × 720, масштабирование выполняет Reveal.js.

Минимальный слайд:

```html
<section class="slide" id="my-new-slide" data-title="Новая тема">
  <header class="slide-head"><span>Раздел</span></header>
  <h2>Новая тема</h2>
  <div class="content">
    <p class="lead">Основная мысль слайда.</p>
  </div>
  <footer class="slide-foot">
    <span>Олимпиадная биология</span><span></span>
  </footer>
</section>
```

Текст с изображением внутри `.content`:

```html
<div class="columns photo-text">
  <div class="photo-column">
    <img class="photo" src="assets/my-photo.jpg" alt="Что показано на фото">
  </div>
  <div><h3>Ключевая мысль</h3><p>Пояснение.</p></div>
</div>
```

Для схем используйте `class="diagram"` внутри `class="diagram-wrap"`: схема сохраняет пропорции, подписи не обрезаются. Фотографии имеют скругление; QR-коды — без скругления. После замены фотографии проверьте, что кадрирование не убрало лица или важные детали.

## Пошаговое объяснение и анимации

В презентации 38 слайдов. Повторные состояния одуванчика и аналогии с кристаллизацией объединены в fragments; добавлен пример с нагреванием газа.

- Стрелка вправо сначала раскрывает следующий fragment, затем переходит к следующему слайду. Влево — обратный порядок. Переход через список начинает выбранный слайд с первого состояния.
- Ответы об одуванчике и этапы естественного отбора появляются по очереди; рисунок остаётся на месте.
- В аналогии с кристаллизацией весь текст виден сразу, по шагам меняется только выделение карточки.
- В примере с нагреванием две одинаковые ёмкости содержат одинаковое число частиц; движение справа быстрее. «Пауза анимации» останавливает обе модели. Системная настройка уменьшения движения отключает анимацию автоматически.
- Видео запускается кнопкой внутри кадра. При уходе со слайда Reveal.js ставит его на паузу.

Постепенное появление — обычная разметка Reveal.js:

```html
<p class="fragment" data-fragment-index="0">Первая мысль</p>
<p class="fragment" data-fragment-index="1">Следующая мысль</p>
```

Одинаковый `data-fragment-index` раскрывает несколько элементов одновременно. Для выделения уже видимого текста используйте пример `.fragment.custom.focus-step` на слайде `slide-36`. Заметки докладчика: `<aside class="notes">Текст подсказки</aside>` в конце секции.

Движение частиц задано в CSS через `@keyframes thermal-motion`. Это качественная иллюстрация, не численная физическая симуляция. Положения редактируются через `--x` и `--y`, длительность цикла — через `--speed`.

## PDF

Откройте `index.html?print-pdf` (либо адрес локального сервера с `?print-pdf`) в Chromium/Chrome. Затем Ctrl+P → сохранить как PDF, альбомная ориентация, без полей, включить печать фона и выключить колонтитулы браузера. Рекомендуемый путь — через локальный сервер.

Все fragments печатаются вместе на одном слайде; анимации останавливаются. Для видео используется его постер.

## Обновить автономную копию

После правок `index.html` выполните `python package.py`. Нужна только стандартная библиотека Python. Скрипт обновляет автономный HTML и ZIP, в том числе после добавления слайдов.

Источник содержания — предоставленный PPTX; исходные научные иллюстрации и фотографии сохранены. Источники нового видео и анимации перечислены в `MEDIA.md`. Содержательные тезисы и даты исходной лекции не проходили отдельный фактчек в рамках задачи по дизайну.
